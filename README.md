## How do you use TiviLive with Kodi?

Kodi's IPTV Simple Client is the obvious route for users who want live channels and an EPG inside Kodi's normal TV interface.

The basic setup concept is:

1. Install **PVR IPTV Simple Client** from Kodi's add-on repository.
2. Add the IPTV provider's M3U playlist as the TV source.
3. Add the XMLTV EPG source when supplied.
4. Load the guide and test several channels, including the ones you actually plan to watch.

Kodi's documentation confirms that IPTV Simple Client supports M3U playlist sources for live TV and XMLTV sources for EPG data.
